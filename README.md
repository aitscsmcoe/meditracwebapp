# 🩺 MediTrac Desktop App

A local desktop application for doctors and clinics built using **React + Electron + Firebase Firestore**, with admin-controlled activation and cloud-based record management.

---

## ⚙️ Features

- Admin dashboard to manage doctor activations
- Doctor registration and activation workflow
- Firestore-based data storage (free tier)
- Role-based authentication (Admin / Doctor)
- Secure local + cloud hybrid setup

---

## 🧱 Tech Stack

- **Frontend**: React (Vite)
- **Desktop Wrapper**: Electron
- **Database**: Firebase Firestore
- **Styling**: Inline + CSS (Segoe UI)
- **Build Tool**: Electron Builder
